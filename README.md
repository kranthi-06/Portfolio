# Portfolio — Kasa Kranthi Kiran

A world-class personal portfolio website built with modern technologies and premium design.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript + React 19
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion, GSAP
- **3D**: Three.js + React Three Fiber
- **Smooth Scroll**: Lenis
- **Icons**: Lucide React
- **Contact**: EmailJS

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## Features

- 🎨 Dark theme with glassmorphism & aurora gradients
- ✨ Premium animations with Framer Motion
- 🖱️ Custom animated cursor
- ⌨️ Command palette (⌘+K)
- 🎯 Floating macOS-style dock navigation
- 📊 Animated counters & progress bars
- 🃏 Spotlight & glass card effects
- 📱 Fully responsive design
- 🔍 SEO optimized
- ♿ Accessible

## Customization

Update your personal data in `lib/constants.ts`:
- Personal info, bio, roles
- Skills & categories
- Experience & timeline
- Projects (LakshyaTrack, CampusPulse)
- Achievements & certifications
- Education details
- Social links

## Deployment

Deploy to Vercel:

```bash
npx vercel
```
